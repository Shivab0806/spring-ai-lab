🚀 Spring AI Lab
A hands-on repository for exploring and mastering Spring AI with real-world examples and enterprise-ready use cases.

This project serves as a learning playground for building AI-powered applications using the Spring ecosystem, covering concepts such as Large Language Models (LLMs), Chat Clients, Retrieval-Augmented Generation (RAG), Vector Databases, Embeddings, Function Calling, Memory, and AI Agents.

📌 Project Goals
Learn and experiment with Spring AI fundamentals.
Integrate LLM providers such as OpenAI and Azure OpenAI.
Build enterprise-grade AI applications using Spring Boot.
Explore Retrieval-Augmented Generation (RAG) architectures.
Work with Vector Databases and Embeddings.
Implement AI Agents and Tool/Function Calling.
Understand conversational memory and context management.
Apply AI capabilities to real-world business use cases.

🚀 Getting Started
Prerequisites
Java 21+
Maven 3.9+
Docker (Optional)
OpenAI or Azure OpenAI API Key
Clone Repository
git clone https://github.com/<your-username>/spring-ai-lab.git
cd spring-ai-lab
Environment Variables
OPENAI_API_KEY=your_api_key
Run Application
mvn spring-boot:run
